🧭 Como usar este kit

  1. Comece pela Leitura Guiada: leia com calma e toque no 🔊 para ouvir o inglês.
  2. Faça o Quiz logo em seguida, enquanto o assunto está fresco.
  3. Use o Resumo para reforçar o que você errou no quiz.
  4. Por último, faça o Simulado como se fosse a prova de verdade, sem consultar.
  5. Seu progresso é salvo sozinho — pode fechar e voltar depois.

👩‍👧 Dica para a mamãe (códigos)

No fim do Quiz e do Simulado, aparece um código secreto (ex.: MED-13-KP ou SIM-17-QT). Os dois números do meio são quantas questões a criança acertou.

O gabarito comentado só abre quando esse código é digitado — assim a criança faz a prova primeiro e só depois vê as respostas, com você por perto. 💛
